Como usar o aplicativo
Usar no computador
1

Baixe o arquivo adega_v2.html para o seu computador.

2

Dê um duplo clique no arquivo — ele abre diretamente no navegador (Chrome, Edge, Firefox ou Safari). Não é necessário instalar nada.

3

Os dados são salvos automaticamente no navegador. Na próxima vez que abrir o arquivo no mesmo computador e navegador, tudo estará exatamente como você deixou.

4

Use ⬇ Exportar para criar um backup externo e ⬆ Importar para restaurá-lo em outro dispositivo.

Usar em máquinas diferentes ou no celular
1

Copie o arquivo adega.html para um pen drive ou envie por e-mail / WhatsApp para qualquer dispositivo.

2

No celular (Android ou iPhone), abra o arquivo pelo Google Chrome ou Safari. No Android você pode tocar no arquivo diretamente pelo gerenciador de arquivos.

3

Para manter os dados sincronizados entre dispositivos, salve o arquivo .json de backup em uma pasta do Google Drive, iCloud ou Dropbox — e importe-o de qualquer aparelho.

Gerenciar múltiplas adegas

O app suporta várias adegas simultâneas. Use o botão ⇄ Adegas no cabeçalho para criar novas adegas ou alternar entre elas. Para transferir um vinho entre adegas, abra o vinho e clique em ⇄ Transferir.

Registrar consumo

Ao abrir um vinho cadastrado, clique em 🍷 Consumido para retirá-lo da adega com uma animação e liberar o espaço. O botão Excluir remove o registro permanentemente sem animação.
